The credit line of the R1 (one of its 2 lines) generates the single BOR line. The link is TEXT50 + amount + FISTL — not the fund, which changes from 633CRP9003 to the office fund.

1 · Staff → Office (Funds Center)

The home office (= the credit FISTL and the BOR FUNDS_CTR) is determined by the employee. The source fields exist in HR; the jump to FISTL needs a mapping table (no standard OM field — HRP1008 only carries BUKRS/GSBER/KOKRS).

6 · Technical derivation (for integration)

Deterministic rules an external app can implement directly. Machine-readable spec: derivation_spec.json.

Value rules (deterministic)

RuleInputOutput
Debit GL + commitment itememployee group PA0001-PERSG1 Professional → HKONT 6046013 · FIPOS 11  |  2 GS/NO → 6046014 · 13
Credit GL—HKONT 7046013 · FIPOS REVENUE (fixed; ~99.5%)

BOR fixed fields—PROCESS SUPL · VERSION 000 · DOCTYPE 1000 · CMMT_ITEM TC · BUDCAT 9F · VALTYPE B1 · BUDGETING_PERIOD 016 · TRANS_CURR USD
FY guardYFMXCHKP (CHTYP CM)FISC_YEAR must be > closed year (today ≥ 2026)

Lookup tables the app needs

TableKey → ValueStatus
STAFF_OFFICE_MAPPERNR → FISTL (home office)built 501 staff · 90% single-office (staff_office_map.json)
OFFICE_CODE_MAPFISTL → 2-digit codebuilt 89 offices (office_code_map.json)
CRP_FUND_MAP(FISTL, funding category) → 633CRP fundGAP category = project funding source; not pattern-derivable (verified) → build from project master / recovery history

Algorithm

build(PERNR, SOURCE_FUND, AMOUNT, PERIOD, FY):     # 4 manual inputs
  office  = STAFF_OFFICE_MAP[PERNR]                # FISTL  (HR)
  persg   = PA0001-PERSG[PERNR]                    # 1=Professional | 2=GS/NO
  dGL,dCI = (6046013,'11') if persg==1 else (6046014,'13')
  fund    = '633CRP' + CRP_FUND_MAP[office,SOURCE_FUND].cat + OFFICE_CODE_MAP[office]
  # R1 (FI):  Dr dGL  GEBER=SOURCE_FUND  FISTL=sector(SOURCE_FUND)  FIPOS=dCI  AMOUNT
  #           Cr 7046013  GEBER=633CRP9003  FISTL=office  FIPOS=REVENUE  AMOUNT
  # BOR: Y_FMKU_0050_CREATE_WITH_COMMIT(PROCESS=SUPL,
  #        ITEM{FUND=fund, FUNDS_CTR=office, CMMT_ITEM=TC, BUDCAT=9F, VALTYPE=B1, FISC_YEAR=FY, TOTAL_AMOUNT=AMOUNT},
  #        PERIOD{BUDGETING_PERIOD=016, PERIOD_AMOUNT=AMOUNT}, TESTRUN='X')
