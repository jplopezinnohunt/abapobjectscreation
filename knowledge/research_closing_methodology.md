# Research Closing Methodology (quality gate before conclusions)

Mandate (user, s079): "Debes tener una metodología que permita primero un CLOSING del research con
garantías de calidad, y luego sobre eso recién hacer las conclusiones y planes." Standard = medical:
you would never base a consequential decision on incomplete, unverified, spun research. A research that
did not CLOSE is worth ZERO — it is not "salvageable" into findings.

## PHASE A — RESEARCH CLOSING (the gate). A research is CLOSED only if ALL pass:
1. **Completeness** — every research question/angle is answered; an explicit coverage check shows no
   unaddressed dimension. A research that STOPPED/FAILED before finishing is NOT closed. → re-run in
   full, or discard. NEVER promote partial/scraped fragments to "findings".
2. **Source grade** — each claim is backed by a graded source (PRIMARY peer-reviewed / official vendor /
   secondary / blog / unreliable). The grade is recorded. A claim resting only on unreliable sources is
   flagged, not accepted as fact.
3. **Adversarial verification** — each claim is independently challenged (≥3 skeptics try to REFUTE;
   ≥2/3 refute → killed). Only surviving claims are accepted. Killed/refuted claims are recorded as such.
4. **Citable evidence** — every accepted claim carries its source (URL / path:line) AND a verbatim quote.
   No claim without evidence enters the closed set (CP-003).
5. **Confidence tier** — each accepted claim labeled HIGH / MEDIUM / LOW by (source grade × verification
   strength). Tiers are explicit, never implied.
6. **Explicit gaps** — what the research did NOT establish is stated as OPEN QUESTIONS, not glossed.
   "Not established" is a valid, required output.
7. **Reproducibility** — the method (queries, sources fetched, verification votes) is recorded so the
   close can be re-run / audited (CP-001 traceability).
8. **No-spin attestation** — failures are reported as failures; the close states plainly what is verified
   vs not. No dressing up an incomplete run as a result.

**The gate is binary.** If any criterion fails, the research is OPEN, not closed — and Phase B cannot start
on it. (The s079 deep research stopped in Fetch with no verification → OPEN → its 484 fragments are NOT
findings and must not feed any plan.)

## PHASE B — CONCLUSIONS & PLANS (only on a CLOSED research)
- Conclusions cite ONLY closed (verified) claims; each conclusion carries the confidence tier + citation
  of the claim(s) it rests on.
- Plans derive from conclusions; each plan item traces to the verified evidence that justifies it.
- Any item resting on a LOW-confidence claim or an OPEN question is labeled an ASSUMPTION / RISK, not a
  fact — and the plan states what would have to be verified to remove the assumption.
- A plan never depends on an OPEN-phase research.

## Operating rules (the guarantees you asked for)
- **A deep-research output counts ONLY if it completed its Verify + Synthesize phases.** Stopped in
  Scope/Search/Fetch = OPEN = invalid. Check the phase state before using ANY output.
- **Do not launch internet-dependent research when the internet is flagged down.** It will not close.
- **Never "salvage" a failed research into findings.** Scraps may become LEADS to verify later, never
  conclusions now.
- **Every presented item carries its evidence status**: VERIFIED (closed) / INFERRED (own reasoning,
  unverified) / NOT-ESTABLISHED. The reader always knows the standing.
- This is CP-001/CP-002/CP-003 applied to research: traceability, preserve-with-structure, precision+evidence.

## Where this plugs in
- The deep-research harness's verify(3-vote)+synthesize phases ARE the closing for web research — but only
  if they RAN. The methodology adds the explicit gate + the no-partial rule + the evidence-status labeling.
- For OWN analysis (no web): the same gate — a claim is "closed" only with citable local evidence
  (path:line, a query result, a verified count) + a confidence tier. Reasoning-only = INFERRED, not fact.
- Phase 1 (process-mining capability inventory) will be rebuilt under this gate: each item tagged
