## SAP learnings (Phase 4b)
- **D01 kernel rejects RFC_READ_TABLE ROWSKIPS>0 without GET_SORTED** (`SAIS E000`), same class of
  quirk as the known P01 ROWSKIPS rejection. Workaround: one call with ROWCOUNT=0 (no paging).
  `rfc_helpers.rfc_read_paginated` is therefore unusable for >batch_size result sets on D01 too.
- **ADT DDIC table read 404s on D01 EhP8** (`/sap/bc/adt/ddic/tables/{name}` + `get_table_structure`).
  Use RFC `DDIF_FIELDINFO_GET` for table structures — consistent with the known "DDIC via DDIF_* on
  EhP8" rule.
- **The HR-WF framework spans 4 packages** (YHR_PA_WF, YHR_OM_WF, YBC, ZHR_DEV) — package ≠ framework
  boundary. TADIR AUTHOR query is the reliable way to find a developer's full footprint.
- **TADIR author ≠ package content**: only 135/740 objects in YHR_PA_WF carry AUTHOR=N_MENARD.
- The v1 reference file `YTHRWF_EVAL_PATH` has **no TADIR object** on D01 — naming drift in the v1
  reference set (eval-path logic = `YCL_WF_UTILITIES=>GET_OBJECTS_WITH_EVAL_PATH`).
- Mail engine discovery: 3-level template-method hierarchy + SO10 templates + `YTBC_MAIL_AUTH`
  non-prod whitelist + `HRUS_D2` substitution chain (details in style guide §6 ext).
